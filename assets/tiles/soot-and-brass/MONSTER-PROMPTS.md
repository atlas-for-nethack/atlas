## Extraction and corrective decisions

All ten source PNGs preserve the exact built-in image output and genuine generated alpha. Source sheet dimensions vary; the registry records explicit pixel bounds measured from whole-image alpha components rather than assuming perfectly aligned rows. The bounds measurement uses alpha greater than8 and8-connected components larger than300 source pixels, unions legitimate detached parts in the same cell, and adds2px margins. Final art uses the build script nominal-cell scaling so small creatures remain small.

Ten cells in source-02 and source-05 contain touching adjacent silhouettes and are deliberately null in the registry. Their independently generated isolated replacements are in source-08 and source-09. Later assignments override earlier sprites for a key. Corrective sheets address dragon color/order, animal-form and human-form lycanthropes, wingless gargoyle, rust monster, owlbear, grid bug, xan, zruty, leocrotta, salamander, quest roles and reference-anchor fidelity.
